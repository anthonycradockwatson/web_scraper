# Web Scraper

A lightweight Python web scraper built to extract and parse data automatically. 

## Features
- Handles multi-page traversal / pagination
- Parses raw HTML into structured formats
- Configurable rate-limiting and error handling

## Tech Stack
- **Language:** Python
- **Libraries:** BeautifulSoup, Requests

## Getting Started

### Prerequisites
Make sure you have Python 3.x installed.

### Installation

1. Clone the repository:
   ```bash
   git clone [https://github.com/anthonycradockwatson/web_scraper.git](https://github.com/anthonycradockwatson/web_scraper.git)
   cd web_scraper
   ```
2. Install Requirements
 ```bash
   pip install -r requirements.txt
```
3. Run the Script
 ```bash
   python main.py
```
